# CallReceiver 사용 안내

Android 휴대폰의 수신 전화번호와 시간을 Windows 팝업으로 보여주는 프로그램입니다.

## 처음 사용하기

1. GitHub Release에서 Windows ZIP을 내려받아 빈 폴더에 압축을 풉니다. EXE와 함께 들어 있는 파일도 같은 폴더에 두세요. .NET을 따로 설치할 필요는 없습니다.
2. `CallReceiver.exe`를 실행합니다. 설정 창 대신 작업 표시줄 오른쪽 트레이에 아이콘이 나타납니다.
3. 트레이 아이콘을 더블클릭하거나 마우스 오른쪽 버튼의 **설정 열기**를 선택합니다.
4. **서버 설정**에서 상태가 **실행 중**인지 확인합니다. 중지 상태라면 **서버 시작**을 누릅니다.
5. **현재 주소**의 IP와 Port, 설정된 API Path를 확인합니다. 기본 Port는 `18080`, API Path는 `/api/call`입니다.
6. 같은 네트워크에 연결한 [모바일 앱](../mobileCallReceive/README.md)에 같은 IP·Port·API Path를 입력하고 저장합니다.
7. 모바일의 **테스트 전화 이벤트 전송**을 눌러 PC에 팝업이 표시되는지 확인합니다. 이후 모바일에서 **시작**을 누르면 실제 수신 전화가 전달됩니다.

예를 들어 현재 주소가 `192.168.0.50:18080`이면 모바일 서버 IP에는 `192.168.0.50`, Port에는 `18080`을 입력합니다. `127.0.0.1`은 PC 자체 테스트용이므로 휴대폰에 입력하지 마세요.

## 주요 설정

| 탭 | 사용 방법 |
|---|---|
| 서버 설정 | 현재 주소·실행 상태 확인, Port·API Path 변경, 서버 시작·중지 |
| 알림 설정 | 모니터·위치·크기·표시 시간, 문구·글꼴·정렬·시간 형식 설정 |
| 프로그램 설정 | Windows 로그인 시 자동 실행, 트레이 동작, 설정 폴더 변경·초기화 |
| 최근 요청 | 받은 요청과 결과 확인, 자세히 보기, 로그 초기화·TXT 저장 |

설정을 변경하면 **설정 저장**을 누르세요. **알림 위치 테스트**는 저장 전 편집값과 입력한 테스트 전화번호로 확인할 수 있습니다. **HTTP 서버 테스트**는 PC 서버 자체를 확인하며, 휴대폰과의 연결은 모바일의 테스트 전송으로 확인하세요.

알림 표시 시간은 `1~9999초`입니다. 표시 중 새 전화가 오면 기존 팝업을 닫고 새 알림을 표시합니다. 전화번호·수신시간의 글꼴 크기를 `0`으로 설정하면 해당 본문 줄을 숨깁니다.

상단 순서는 1번·2번·3번에서 안내 문구·시간·전화번호·표시 안함을 선택합니다. 같은 항목을 다른 칸으로 옮길 때는 기존 칸을 먼저 표시 안함으로 바꾸세요. 본문 접두 문구는 콜론까지 직접 입력하며 비워 두면 값만 표시합니다.

본문 전화번호에는 인식 가능한 국내 번호에만 하이픈을 붙입니다. 예: `010-1234-5678`, `02-1234-5678`, `070-1234-5678`, `1588-1588`. 상단 caption·창 제목과 요청 로그에는 원본 번호를 유지합니다.

## 설정 파일과 로그

기본 저장 위치는 실행 파일과 같은 폴더입니다.

- `settings.json`: 프로그램 설정
- `events.sqlite3`: 접수한 전화 이벤트와 중복 방지 기록
- `logs/CallReceiver-yyyyMMdd.log`: 날짜별 요청 로그

최근 요청은 화면에 200건까지 표시하고 재실행 후에도 복원합니다. **자세히 보기**에서 받은 데이터·출발지·처리 결과를 확인할 수 있습니다. **로그 초기화**는 화면 목록과 현재 로그 폴더의 기록을 함께 삭제하며, **TXT로 저장**은 현재 목록을 내보냅니다.

설정 폴더를 변경하면 트레이의 **종료**로 정상 종료한 뒤 다시 실행하세요. 설정과 이벤트 DB는 이전되지만 기존 로그는 이전 폴더에 남습니다. **설정 초기화**는 설정만 기본값으로 되돌리며 이벤트 DB와 로그는 유지합니다.

## 연결이 안 될 때

- PC와 휴대폰이 같은 네트워크에 연결되어 있는지, 모바일 설정이 PC의 현재 주소·Port·API Path와 일치하는지 확인하세요.
- PC 주소는 프로그램 실행과 서버 시작 시 다시 감지합니다. 주소가 달라졌다면 모바일 설정도 변경하세요.
- Windows 방화벽에서 해당 프로그램의 수신 연결과 현재 네트워크 프로필을 허용했는지 확인하세요.
- PC는 켜진 상태여야 합니다. 절전·최대 절전 상태에서는 요청에 응답하지 못합니다.
- 모바일의 상세 로그와 PC의 최근 요청을 함께 확인하세요. 모바일에서 Timeout이 발생해도 PC가 이미 접수했을 수 있습니다.

설정 창을 닫으면 기본적으로 트레이에 남아 동작합니다. 프로그램을 완전히 끝내려면 트레이 메뉴의 **종료**를 선택하세요.

배포 방법은 [GitHub Release 안내](../docs/RELEASE.md)를 참고하세요.
